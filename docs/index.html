Sound Scraper

Download audio from Soundgasm and Reddit (r/gonewildaudio) using Python, PRAW, and BeautifulSoup.

View on GitHub

Scripts

  • soundgasm.py — Download audio from soundgasm.net user pages or individual URLs
  • redditGWA.py — Scrape Reddit subreddit posts, extract Soundgasm links, download audio
  • 4chan_scraper.py — List 4chan boards and threads

Quick Start

pip install -r requirements.txt
cp praw.ini.example praw.ini
# Edit praw.ini with Reddit API credentials
python soundgasm.py
python redditGWA.py

Configuration

  • SOUNDGASM_OUTPUT_DIR — output directory (default: ~/audio/Soundgasm)
  • praw.ini — Reddit API credentials (client_id, client_secret)
